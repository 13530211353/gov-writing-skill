# G端公文撰写 Skill

适用于Claude的G端/政企类中文公文撰写规范，覆盖结构逻辑、段落构造、数据标准和排版格式。

## 适用场景

- 政府项目申报材料
- 验收报告、项目方案
- 述职报告、政策简报
- 一切输出对象为政府部门的中文文档

## 使用方法

将 `skill.md` 的内容添加到Claude的自定义skill中，之后在对话中提及G端、公文、申报、政企等关键词时会自动触发本规范。

## 规范内容

- **文档结构**：每章3-4部分，章节间内容对应，内部递进逻辑（如龙岗→深圳→全国→全球）
- **段落构造**：论点→论据A→论据B→结论四句式，150-200字/段
- **数据规范**：零幻觉原则，所有数据须可在政府官网或主流媒体核实
- **排版格式**：方正小标宋/黑体/楷体/仿宋字体层级，28.95磅行距
- **文风要求**：公文体，避免AI感，禁用破折号，慎用分号
